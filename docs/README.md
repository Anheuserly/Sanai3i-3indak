## 🏛️ المبادئ الجوهرية الثابتة لمنصة الويب

1. **لغة عربية خالصة:** واجهة وتجربة ومصطلحات باللغة العربية حصراً مع خط `Cairo`.
2. **نابلس، فلسطين:** تغطية كافة أحياء ومناطق نابلس (رفيديا، المخفية، البلدة القديمة، المعاجين، الجبل الشمالي والجنوبي، شارع فيصل، القدس...).
3. **أربعة أدوار صارمة:** زبون (`customer`)، صنايعي (`worker`)، أدمن (`admin`)، ومالك التطبيق (`owner_admin`).
4. **تجريد مالي تام:** انعدام أي بوابات دفع، بطاقات، أو محافظ؛ الدفع نقدي ومباشر بعد إتمام الخدمة.
5. **مكافحة الطلبات الوهمية:** زر إبلاغ للصنائعية، مراجعة إدارية، وسجل تحذيرات متدرج.
